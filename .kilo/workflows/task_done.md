# Task Done: Final Verification & Report

Выполни финальную проверку состояния задачи и сформируй отчёт:

1. Запусти `git log --oneline -5` для просмотра последних коммитов в текущей ветке.
2. Запусти `git status --short` для проверки незакоммиченных файлов.
3. Запусти Quality Gate: `ruff check .` и `make ai-smoke`.

Сформируй отчёт строго по шаблону:
- **Done:** краткий список выполненных задач и коммитов.
- **Not committed:** список незакоммиченных файлов (если есть).
- **Verification:** статус `ruff`, `pytest` и `make ai-smoke` (OK / FAIL).
- **Next step:** предложи `/ship` (если всё готово) или укажи, что нужно доделать/исправить.
