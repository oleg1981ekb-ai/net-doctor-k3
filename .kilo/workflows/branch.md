# Branch: Create a New Feature Branch

Подготовь репозиторий к работе над новой задачей. Действуй строго по шагам:

0. **Справка (`-h` / `--help`)**: если указан флаг `-h` или `--help`, не запускай git-команды, а сразу выведи справку по команде `/branch` и остановись:
   - `feat/<название>` — новая функциональность
   - `fix/<название>` — исправление бага
   - `refactor/<название>` — улучшение кода без изменения логики
   - `docs/<название>` — документация и регламенты

1. **Проверка чистоты рабочей директории**: запусти `git status`. Убедись, что нет незакоммиченных изменений. Если есть правки — остановись, покажи их и спроси, нужно ли их сохранить (`git stash`) или закоммитить.
2. **Синхронизация с основной веткой**: переключись на `main` (`git checkout main`), подтяни свежие изменения (`git pull origin main`) и очисти ссылки (`git fetch --prune`).
3. **Очистка влитых веток**: проверь `git branch --merged`. Удали влитые локальные ветки (`git branch -d <имя_ветки>`), кроме `main`.
4. **Нейминг новой ветки**: если название задачи не указано, спроси краткое описание и сформируй имя ветки в нижнем регистре на английском через дефис (`feat/...`, `fix/...`, `refactor/...`, `docs/...`).
5. **Создание и переключение**: создай ветку от актуального `main` командой `git checkout -b <имя_ветки>`.
6. **Отчёт**: выведи `git branch --show-current` и подтверди готовность.
